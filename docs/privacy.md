# README Pro privacy information

Effective October 31, 2026. Publisher: Eniola Akinpelumi.

## The packaged skill

README Pro is a set of agent instructions and reference documents. The released package has no publisher-operated backend, telemetry, analytics, account system, or MCP server. It does not contain code that sends your repository to the publisher. Installing or invoking the skill does not give the publisher access to your files, conversations, or credentials.

## Processing by the host

The host agent, such as Codex, reads the repository material needed to perform your request and may execute commands or access links under its permissions. Repository contents, prompts, and outputs may be processed by OpenAI according to your product, account settings, and the terms and privacy information applicable to that host. README Pro does not change those settings or provide a separate data-retention guarantee. See [OpenAI's privacy policy](https://openai.com/policies/privacy-policy/) and your account's data controls.

The skill tells the agent to use sanitized configuration examples and synthetic inputs, avoid reproducing secret values, and report checks it could not perform. Review what you share with any agent and what its output would publish.

## GitHub and support

GitHub hosts the source and release downloads and handles access under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). If you voluntarily post an issue, comment, or pull request, the publisher and other visitors may read what you post. Public issues are not a private support channel. Do not include credentials, proprietary source, personal information, or private repository contents.

README Pro provides no separate support database or automatic deletion mechanism. Manage or delete content you posted using GitHub's controls and policies. For questions about this package, use [the issue tracker](https://github.com/eni-akin/readme_pro/issues) with a minimal, sanitized example.
