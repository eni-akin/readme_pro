# Reference notes

The author supplied [GitHub README Research](https://chatgpt.com/share/6ae4f7ff-53bc-83e8-9a7d-798f5d06c1f0), a shared discussion comparing professional project READMEs. Its principles informed this skill: deliberate information order, visible proof, a dependable first result, reader-specific depth, and honest scope.

These primary project pages are useful places to study different approaches. They are external inspiration, not fixtures, dependencies, endorsements, or evidence about the user's project. Their contents can change.

- [uv](https://github.com/astral-sh/uv)
- [Excalidraw](https://github.com/excalidraw/excalidraw)
- [micrograd](https://github.com/karpathy/micrograd)
- [ripgrep](https://github.com/BurntSushi/ripgrep)
- [Datasette](https://github.com/simonw/datasette)
- [Whisper](https://github.com/openai/whisper)

For GitHub-specific behavior, consult the current [README documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) and [basic formatting guidance](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax). The skill is self-contained; these links are optional reading.

Examples in this repository are original fictional illustrations. Third-party README text, screenshots, logos, and layouts are not bundled.
