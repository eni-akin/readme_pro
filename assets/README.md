# README Pro brand assets

These assets use the supplied **Sparkle Page** logo kit. The mark is a document page with a folded corner and four-point sparkles: “Your README, polished.”

| File | Use |
| --- | --- |
| [logo.svg](logo.svg) | Full-colour primary symbol used in the README; display at 32 px or larger |
| [icon.svg](icon.svg) | App-icon SVG master: simplified white page and sparkle on a violet rounded square |
| [icon.png](icon.png) | 1024 × 1024 PNG rendered from the app-icon master; used by the plugin listing and composer |

The SVG masters are copied unchanged from the supplied kit's `final-symbol.svg` and `final-symbol-app-icon.svg`. They contain paths rather than live wordmark text, so they have no font dependency. The primary symbol uses Violet `#7C3AED`, Deep Violet `#6D28D9`, and Gold `#FBBF24`; the app-icon variant is the kit's white-on-violet treatment.

Keep the original proportions and colours. Allow clear space around the symbol equal to the folded corner's height. The kit's sparkle angles and optical balance are intentional; do not snap or recenter them during export. Use the simplified app icon for compact plugin surfaces. The horizontal and stacked wordmarks are not included here because the supplied kit identifies their live text as requiring outline conversion before production use.

This branding was introduced in version **0.1.1**. See [GitHub Releases](https://github.com/eni-akin/readme_pro/releases) for versioned packages. The published 0.1.0 ZIP and its validation record describe the previous icon and remain unchanged. Official OpenAI directory submission remains deferred. Trademark clearance was not performed, as noted in the supplied kit.
